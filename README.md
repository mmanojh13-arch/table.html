# 🌐 HTML Table Design Project

A simple and attractive web development project built using **HTML5 and CSS3**. This project displays a stylish table with colorful headings, a gradient background, glassmorphism effects, and hover animations.

## ✨ Features

- 🎨 Beautiful animated blue gradient background
- 🧡 HTML5 logo and attractive heading
- 🌈 Different colors for Name, Age, and Salary headings
- 🪟 Glassmorphism table container
- ✨ Smooth hover animations on table rows
- 📱 Responsive design for mobile and desktop screens
- 💰 Sample employee salary details

## 🛠️ Technologies Used

- **HTML5** – Structure of the webpage
- **CSS3** – Styling, gradients, animations, and responsive layout
- **SVG** – HTML5 logo illustration

## 📂 Project Structure

```text
html-table-project/
├── index.html
└── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Move your mouse over the table rows to see the hover effects.

No additional software or dependencies are required.

## 📸 Project Preview

The webpage includes a blue gradient background, a colorful heading, and a modern table displaying names, ages, and salaries.

- Understand HTML table elements such as `<table>`, `<tr>`, `<th>`, and `<td>`.
- Apply CSS colors, gradients, shadows, and animations.
